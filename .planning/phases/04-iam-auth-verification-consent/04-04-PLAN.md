## Trust Boundaries

| Boundary                    | Description                                                                                                  |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Inngest cloud ↔ /api/inngest | Inngest signs every webhook with INNGEST_SIGNING_KEY (production); SDK auto-validates. Local dev uses no signing. |

## STRIDE Threat Register

| Threat ID  | Category               | Component                                | Disposition | Mitigation Plan                                                                                                                                                                                                                            |
| ---------- | ---------------------- | ---------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| T-04-04-01 | Spoofing               | Forged Inngest webhook                   | mitigate    | INNGEST_SIGNING_KEY validation is automatic in `inngest/next` serve(). In production the signing key is REQUIRED (server-env optional() means undefined is allowed only in dev — production env must populate it).                          |
| T-04-04-02 | Denial of Service      | Cron firing on every minute               | mitigate    | `auth-throttle-cleanup` is `cron: '17 * * * *'` (hourly at minute 17), not '\* \* \* \* \*'. UI-SPEC discretion locks this. Spreads load across the hour.                                                                                  |
| T-04-04-03 | Information Disclosure | Stub returns leak schema                  | accept      | Stubs return `{status: 'not_implemented'}` — no PII, no system info. Dashboard visibility is the intended behavior.                                                                                                                         |
| T-04-04-04 | Tampering              | Cleanup cron deletes wrong rows           | mitigate    | DELETE WHERE `window_start < cutoff` is parameterized via Drizzle; cutoff = `floor((now - 2h) / 60s)`. Integration test (Plan 04 task 3) asserts only old rows are deleted.                                                                  |
| T-04-04-05 | Repudiation            | Function failure leaves no trace          | mitigate    | Inngest dashboard logs every function invocation by default (this is one reason CLAUDE.md mandates Inngest over raw cron). Sentry capture lands in later phases when real functions ship.                                                  |

    // Phase 4 D-16/D-17: IAM context Inngest functions.
    // Real: auth-throttle-cleanup (cron) + iam-password-reset-requested (Plan 09 wires real logic; Plan 04 ships event signature only)
    // Stubs: iam-process-deletion (Phase 11), iam-generate-export (Phase 11)
    import { sql } from "drizzle-orm";
    import { inngest } from "@shared/inngest/client";
    import { db } from "@contexts/iam/infrastructure/db/client";
    import { authThrottle } from "@contexts/iam/infrastructure/db/schema";
    import { computeWindowStart } from "@contexts/iam/infrastructure/db/auth-throttle";

    /**
     * REAL CRON — Phase 4 D-12 + UI-SPEC Discretion.
     * Hourly at minute 17. Deletes auth_throttle rows older than 2 hours.
     * 2-hour retention covers the 5-minute lockout window plus headroom for clock skew.
     */
    const authThrottleCleanup = inngest.createFunction(
      { id: "auth-throttle-cleanup" },
      { cron: "17 * * * *" },
      async ({ step }) => {
        const deletedCount = await step.run("delete-old-rows", async () => {
          const cutoff = computeWindowStart(Date.now() - 2 * 60 * 60 * 1000);  // 2 hours ago
          const result = await db
            .delete(authThrottle)
            .where(sql`${authThrottle.window_start} < ${cutoff}`)
            .returning({ ip: authThrottle.ip });
          return result.length;
        });
        return { deletedCount };
      }
    );

    /**
     * REAL — Phase 4 D-11.
