## Spacing Scale

PRD §17 mandates strict 8 pt grid; 4 px allowed only for tight icon-to-label gaps.

| Token | Value | Usage |
|-------|-------|-------|
| `space-0.5` | 2 px | Internal text-icon optical alignment only (rare) |
| `space-1` | 4 px | Tight icon-to-label gap (sole permitted sub-8 use) |
| `space-2` | 8 px | Compact element spacing, button icon gap |
| `space-3` | 12 px | Permitted only inside composed chip / pill primitives |
| `space-4` | 16 px | Default element gap, card padding, catalog grid card-to-card gap |
| `space-5` | 20 px | Mobile outer gutters |
| `space-6` | 24 px | Modal sheet top-corner radius / inner-section gaps |
| `space-8` | 32 px | Section gaps Home + Plant Profile, desktop outer gutters |
| `space-12` | 48 px | Major section breaks, Primary button height |
| `space-14` | 56 px | Bottom-nav content height (before safe-area inset) |
| `space-18` | 72 px | Capture button diameter (PRD §17 fixed) |
| `space-24` | 96 px | Empty Home capture-button minimum clearance (per PRD §17) |

**Exceptions (intentional, locked by PRD §17):**

- **44 px** — minimum tactile touch-target floor where a full 48 px primary button cannot fit (icon-only inputs); honored as accessibility floor, not a spacing slot.
- **3 px** — focus ring / nav active-indicator stroke; visual stroke, not spacing.
- **1.5 px** — input/button border, Lucide stroke; visual stroke, not spacing.
- Card border radius `16 px`, button radius `8 px`, modal-sheet top-corner radius `24 px`, pill chip radius `999 px` — geometric tokens, locked separately by PRD §17.

## Typography

> Exceeds the template's 3-4 size / 2 weight heuristic by design — locked by PRD §17 / UI-01. Six roles across two families at three weights.

### Type Scale (mobile)

| Role | Family | Size / Line | Weight | Tracking | Color (light / dark) | Usage |
|------|--------|-------------|--------|----------|----------------------|-------|
| Hero | Source Serif 4 | 32 / 38 px | 500 | normal | Forest Ink / Moonpaper | Empty-state headlines, hero composition |
| Title | Source Serif 4 | 24 / 30 px | 500 | normal | Forest Ink / Moonpaper | Screen titles, plant names |
| Section label | Plus Jakarta Sans | 14 / 18 px | 600 | UPPERCASE +4 % | Forest Ink / Moonpaper | "HOJE", "MEU JARDIM" — section dividers only |
| Body | Plus Jakarta Sans | 16 / 24 px | 400 | normal | Forest Ink / Moonpaper | Default reading text. Minimum 16 px regardless of viewport. |
| Metadata | Plus Jakarta Sans | 14 / 20 px | 400 | normal | Calm Slate / Lantern Slate | Secondary text, placeholder, inactive |
| Button | Plus Jakarta Sans | 16 / 20 px | 600 | +2 % | by button variant | All buttons; never Source Serif 4 |

**Rules (NON-NEGOTIABLE):**

- NEVER mix Source Serif 4 into buttons or form fields.
- NEVER use generic serifs (Times, Georgia, Garamond, Palatino) or Inter as fallback.
- NEVER use all-caps headlines; uppercase only at the 14 px Section-label slot at +4 % tracking.
- NEVER use condensed / ultra-tight tracking anywhere.
- NEVER ship fixed-height text containers; clipping under largest Dynamic Type / browser zoom = bug. Use `clamp()` for headlines; line-height stays 1.4–1.55.
- Latin scientific names render via `<i lang="la">` (`ScientificName` component at `src/shared/typography/scientific-name.tsx` — Claude's discretion).
- Body copy may use `hyphens: auto` for long scientific names; headlines do NOT hyphenate.

### 60 / 30 / 10 Accent Discipline

| Layer | Value | Reserved For |
|-------|-------|--------------|
| **Dominant (60 %)** | Paper Cream `#FBF7EF` (light) / Night Cream `#1A1613` (dark) | Primary app bg of every surface |
| **Secondary (30 %)** | Warm Ivory `#FFFDF7` (light) / Embered Surface `#231E1A` (dark) | Cards, sheets, modal sheet bg, plant card bg, banner bg |
| **Accent (10 %)** | Canopy Green `#1F4D35` (light) / Canopy Sprout `#6FAE8A` (dark) | **Reserved-for list (closed):** Primary button fills, Tertiary text-link labels, Secondary button stroke + label, bottom-nav active 3 px top-indicator bar, bottom-nav active filled-Lucide icon, focus ring (3 px @ 40 % opacity), input focus stroke, capture button fill, brand logo, hyperlinks, Toggle "on" track. **Never:** decorative gradients, body text, non-active nav items, non-CTA UI chrome. |
| Destructive (semantic, NOT decorative) | Urgent Poppy `#C73E1D` (light) / Urgent Blossom `#E8593A` (dark) | **Toxicity badge fill ONLY + destructive confirm fill ONLY.** Never form errors, never network failures, never generic "something went wrong." |
| Form-error / overdue (semantic) | Overdue Rust `#A14A2C` (light) / Overdue Copper `#C96A44` (dark) | Form validation strokes / icons / helper text + overdue reminder section. Distinct from toxicity to keep the safety signal clean. |

**Accent discipline (PRD §17):** Canopy Green / Sprout is the ONLY brand accent. Terracotta, Honey Amber, Urgent Poppy, Overdue Rust, Trust Teal (and dark counterparts) are **semantic signals** — never decorative, marketing, or onboarding accents. Any pair not in the contrast ledger above is unapproved.

### Banned color patterns (lint-enforced)

- NO pure black `#000000` / `#000` / `#0%`. Use Forest Ink (light) / Night Cream (dark).
- NO pure white `#FFFFFF` / `#FFF`. Use Paper Cream (light) / Moonpaper / Warm Ivory (dark).
- NO gradient text fills (`linear-gradient` over `color` / `-webkit-text-fill-color`).
- NO `backdrop-filter` (glassmorphism / frosted blur).
- NO secondary accent "just to add warmth" — add Paper / Night Cream surface area + a real plant photo, not another color.
- NO dark-mode palette derived by inverting light tokens (use the Veranda-at-dusk variant only).

### Empty-state primitive contract (UI-18)

Every empty state composed in Phase 3 (and every later phase consuming the primitive) MUST carry exactly four parts in this order:

1. **Sage line-art illustration** — Understory Sage / Dusk Sage `currentColor` SVG, `stroke-width: 1.5px`, no fills (D-35). Decorative; `aria-hidden="true"`.
2. **Source Serif 4 headline** — welcoming, never apologetic ("Sua estante ainda está esperando a primeira planta." not "Nada por aqui").
3. **Calm Slate / Lantern Slate hint** — Plus Jakarta Sans 14, supportive context.
4. **Exactly ONE Canopy Green / Sprout primary CTA.** No secondary button. No "Saiba mais."

**Banned in empty states:** stock photos, generic shells reused across screens, "Nada por aqui" apologies, multiple CTAs, AI clichés ("Eleve seu jardim", "Desbloqueie o potencial").

### Inline error contract (UI-19)

Every inline error MUST expose all three:

1. **CAUSE** copy — what went wrong, plain language.
2. **RECOVERY** copy — what the user can do next.
3. **Retry path** — visible, single Canopy CTA. "Algo deu errado" with no next step is forbidden.

**Banned in errors:** Urgent Poppy fill (toxicity + destructive only), full-screen red wall, color-only signal.

### Destructive confirmations (Phase 3 surfaces)

Phase 3 has no real destructive flows; the modal-sheet primitive ships and downstream phases plug in confirmations. Contract for downstream consumers:

| Action | i18n key (placeholder) | Copy pattern |
|--------|------------------------|--------------|
| Generic destructive cancel | `dialog.destructive.cancel` | `Cancelar` (always SECONDARY, layout-first per PRD §17) |
| Generic destructive confirm | `dialog.destructive.confirm` | `{verb specific to action}` — e.g. `Excluir planta` (Urgent Poppy fill, single noun + verb, never "Sim/OK") |

## Motion Contract

Spring-physics, NOT easing-curve. Weighty + organic, never bouncy-cartoonish (PRD §17).

### Spring presets (`src/shared/motion/springs.ts` — D-07)

| Name | Params | Used For |
|------|--------|----------|
| `springs.primary` | `{ stiffness: 120, damping: 18, mass: 1 }` (~240 ms enter / ~180 ms exit) | Button press, modal-sheet reveal, tab switch, toast in/out |
| `springs.captureBounce` | spring scale `1.00 → 1.03 → 1.00` | THE single tactile bounce in the system (capture button press) |
| `springs.breathing` | scale `1.00 → 1.02` over 3.2 s `easeInOut`, `repeat: Infinity` | Empty Home capture-button breathing loop. THE only perpetual micro-interaction. |

### Other motion rules

| Surface | Rule |
|---------|------|
| List reveal cascade | Catalog grid + care-card rows: 60 ms cascade per item, opacity 0→1 + translateY 8 px → 0. Never mount lists instantly. (Lists ship in Phase 5+; Phase 3 ships the cascade utility.) |
| Bottom-nav active indicator | 3 px Canopy bar slides via `transform: translateX()` keyed on active tab index, `transition: transform 240 ms cubic-bezier(.2,.8,.2,1)`. CSS-only. |
| Route transitions | **Static — no animation.** Instant content swap + programmatic focus move. Predictable, accessible (D-09). |
| Celebrations (first plant, streak) | Brief Terracotta accent flourish, single element, ≤ 600 ms. NEVER full-screen confetti. (Owning phases.) |
| Animation primitives | ONLY `transform` + `opacity`. NEVER `top`, `left`, `width`, `height`. NEVER `backdrop-filter`. |

### `prefers-reduced-motion` enforcement (three-layer per D-08)

1. **Runtime** — `useReducedMotion()` from `motion` library; consumed by every spring-driven component to drop animation props or substitute static state.
2. **CSS** — Tailwind `motion-reduce:` variant guards every CSS animation (shimmer, breathing, indicator slide).
3. **Lint** — custom ESLint rule warns on `@keyframes` declarations without a paired `motion-reduce:` fallback.

### Reduced-motion fallbacks (PRD §17)

| Standard motion | Reduced-motion equivalent |
|-----------------|---------------------------|
| Skeleton shimmer | Static block + 80 ms opacity fade-in |
| Breathing loop | Stops at scale 1; static |
| 60 ms list cascade | Collapses to instant 120 ms opacity fade |
| Spring transitions | 120 ms linear crossfade |
| Terracotta celebration | 200 ms color tint (no scale / translation) |
| Capture button 1.03 bounce | No scale; opacity flash only on tap |

Motion is NEVER the sole indicator of state change (UI-22).

## Accessibility Contract (UI-03 / UI-22)

### Focus ring (PRD §17 GLOBAL)

`outline: 3px solid {Canopy Green / Sprout @ 40% opacity}; outline-offset: 2px; border-radius: 8px` matching element shape. 40 % opacity is the MINIMUM that clears the 3 : 1 UI-graphic floor on Paper / Night Cream — never lower to 20 %.

### Keyboard navigation

- Tab order = visual reading order across every surface. Skip-link "Ir para o conteúdo principal" first focusable, visible on focus.
- Modal sheet traps focus until dismissed; first focusable receives focus; close returns focus to invoker.
- Bottom-nav tabs reachable via arrow keys (Radix Tabs pattern) and Tab.
- After every route change, focus moves programmatically to `<main tabIndex={-1} aria-label="Conteúdo principal">` (D-24).

### Color is never the sole signal (UI-22)

| State | Redundant cues required |
|-------|-------------------------|
| Form-field error | 1.5 px Overdue stroke + filled alert icon + Overdue helper text (3 cues) |
| Toxicity (Phase 7) | icon + filled badge + literal text + striped border + SR `role="alert"` + haptic (6 cues) |
| Confidence (Phase 6) | numeric % + text + bar + segments (4 cues) |
| Subscription status | Always paired with text label |
| Offline / read-only banners | Icon + text |
| Bottom-nav active state | Filled icon + 3 px top bar + 600-weight label (3 cues) |

### Live regions

- `aria-live="polite"` on async-state announcements (loading, success).
- `role="alert"` on error states + toxicity badge full phrase.
- Loading states announced ("Identificando sua planta") — Phase 6+ surfaces; Phase 3 ships the live-region wrapper.

### Image alt text rules

- Decorative SVG illustrations (empty-state line-art, brand mark): `aria-hidden="true"`.
- User-uploaded photos (Phase 5+): programmatic accessible name from context (`name` + `nickname` if present). NO empty / filename-based alt allowed.

### Haptics

- Capture button tap → light impact (Phase 6 surfaces; Phase 3 primitive ships hook).
- Toxicity first-reveal per session → warning notification (Phase 7).
- First plant added / streak → success notification, ONCE (Phase 5 / 8).
- Destructive confirm tap → medium impact.
- **Transient errors (network, validation) → NO haptic.** Haptic noise on non-critical events trains users to ignore.

### Verification gates (D-33, D-34)

- `@axe-core/playwright` runs on every placeholder page **in both themes and both motion preferences**, gating CI on `serious` + `critical` violations; warns on `moderate`.
- Playwright snapshot tests for placeholder pages, both themes, both motion preferences. Date / time / random IDs masked via `data-snapshot-mask="true"`.

## Banned Patterns (UI-25 — Lint-Enforced)

PRD §17 ships these as the explicit guardrail list; D-32 wires Stylelint + ESLint + Vitest snapshot gates so violations fail CI.

### Visual slop

- NO emojis in any UI copy / labels / buttons / empty states. Plant icons = Lucide. (ESLint custom rule.)
- NO pure black `#000000` / `#000`. Use Forest Ink `#143424` (light) / Night Cream `#1A1613` (dark). (Stylelint `declaration-property-value-disallowed-list`.)
- NO pure white `#FFFFFF` / `#FFF`. Use Paper Cream `#FBF7EF` (light) / Moonpaper / Warm Ivory (dark). (Stylelint.)
- NO neon, outer glow, drop-shadow fakery beyond the two elevation levels.
- NO glassmorphism / frosted blur / `backdrop-filter`. (Stylelint.)
- NO neumorphism (multi-shadow inset+outset).
- NO gradient headline text. NO gradient buttons. Flat fills only. (Stylelint `function-disallowed-list` for `linear-gradient` on text fills.)
- NO overlapping text + imagery (inline plant-thumbnail in hero composition is the ONLY approved exception; Phase 5+).
- NO mixed icon sets within a screen. Lucide only. (ESLint banned-imports custom rule.)

### Typography slop

- NO Inter. (ESLint banned-imports rule on `next/font/google` `Inter`.)
- NO generic serifs (Times, Georgia, Garamond, Palatino). (Stylelint disallowed `@font-face` family list.)
- NO all-caps headlines. Uppercase reserved for the 14 px Section-label slot at +4 % tracking.
- NO `LABEL // 2026` / `SYSTEM // V1.1` formatting (lazy AI convention).
- NO condensed / ultra-tight tracking.
- NO fixed-height text containers that clip when text scales up.

### Color slop

- Terracotta / Honey Amber / Urgent Poppy / Overdue Rust / Trust Teal (and dark counterparts) = SEMANTIC SIGNALS only. Never decorative CTA, bg, marketing accent.
- Urgent Poppy / Blossom NEVER for form errors, network failures, generic "something went wrong." Toxicity + destructive only.
- NO secondary accent "just to add warmth." If a screen feels cold, add Paper / Night Cream surface area + a real plant photo, not another color.
- NO dark-mode palette derived by inverting light tokens.
- NO contrast pair not in the contrast ledger above.

### Layout slop

- NO centered hero (headline + subtitle + button stacked vertically on axis). Heroes asymmetric.
- NO 3-equal-card "Recursos" / "Features" row.
- NO bouncing chevrons, "Role para baixo," scroll-hint arrows, "Swipe down."
- NO floating AI-chatbot bubble in corner.
- NO sidebar nav on mobile or desktop. Bottom nav only.
- NO fixed chrome without safe-area padding. NO content hidden behind bottom nav.

### Content slop

- NO fabricated data (no `99.8% de precisão`, no `50.000 plantas catalogadas`, no `4.9★ na App Store`). Use `[metric]` placeholders or omit.
- NO fake system-metrics dashboard blocks (`SYSTEM PERFORMANCE`, `KEY STATISTICS`).
- NO AI clichés (`Eleve seu jardim`, `Desbloqueie o potencial`, `Revolucione`, `Next-gen`, `Seamless`, `Unleash`).
- NO generic placeholder names (`Maria Silva`, `João Santos`, `Acme Plantas`). Use first-name-only pt-BR (`Clara`, `Rafael`), clearly illustrative.
- NO broken Unsplash hotlinks. Use local assets, `picsum.photos`, or SVG illustrations.

### Interaction slop

- NO custom mouse cursors.
- NO pulsing / shimmering / floating animations beyond capture-button breathing loop.
- NO "tap anywhere to dismiss" without visible dismiss affordance (PRD §17 modal-sheet rule: drag handle + labelled "Fechar" button required; tap-scrim allowed only in addition).
- NO confetti explosions.
- NO interaction depends on hover. Hover is decorative amplification only, never load-bearing.
- NO perpetual animation without reduced-motion fallback.
- NO haptic feedback on transient errors / non-critical events.
- NO circular spinners. Skeleton shimmer only (UI-17).
- NO View Transitions API in Phase 3 (D-09 — static route transitions). Revisit post-MVP.
- NO custom PWA install prompt (D-19 — browser default only in Phase 3).
