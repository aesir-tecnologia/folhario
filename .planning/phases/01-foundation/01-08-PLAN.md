Step 1 — Create directory `.github/workflows/` if missing, then write `.github/workflows/ci.yml` with this EXACT content (copy verbatim, preserving indentation and all GitHub Actions expression syntax):

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

env:
  NODE_VERSION: "22"

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    timeout-minutes: 20

    services:
      postgres:
        image: postgres:17-alpine
        env:
          POSTGRES_USER: postgres
          POSTGRES_PASSWORD: postgres
          POSTGRES_DB: folhario_test
        ports: ["5432:5432"]
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - uses: actions/checkout@v5

      - name: Enable Corepack (pnpm)
        run: corepack enable

      - name: Setup Node
        uses: actions/setup-node@v5
        with:
          node-version: ${{ env.NODE_VERSION }}

      - name: Get pnpm store path
        id: pnpm-cache
        shell: bash
        run: echo "STORE_PATH=$(pnpm store path --silent)" >> "$GITHUB_OUTPUT"

      - name: Cache pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ steps.pnpm-cache.outputs.STORE_PATH }}
          key: pnpm-store-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            pnpm-store-${{ runner.os }}-

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Lint
        run: pnpm lint

      - name: Typecheck
        run: pnpm typecheck

      - name: Unit tests
        env:
          DATABASE_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          DATABASE_POOL_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          SUPABASE_SERVICE_ROLE_KEY: test
          NEXT_PUBLIC_SUPABASE_URL: http://localhost:54321
          NEXT_PUBLIC_SUPABASE_ANON_KEY: anon
          IDENTIFICATION_PROVIDER_MODE: stub
        run: pnpm test:unit

      - name: Integration tests
        env:
          DATABASE_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          DATABASE_POOL_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          SUPABASE_SERVICE_ROLE_KEY: test
          NEXT_PUBLIC_SUPABASE_URL: http://localhost:54321
          NEXT_PUBLIC_SUPABASE_ANON_KEY: anon
          IDENTIFICATION_PROVIDER_MODE: stub
        run: pnpm test:integration

      - name: Build
        env:
          DATABASE_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          DATABASE_POOL_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          SUPABASE_SERVICE_ROLE_KEY: test
          NEXT_PUBLIC_SUPABASE_URL: http://localhost:54321
          NEXT_PUBLIC_SUPABASE_ANON_KEY: anon
          IDENTIFICATION_PROVIDER_MODE: stub
        run: pnpm build

      - name: Cache Playwright browsers
        uses: actions/cache@v4
        with:
          path: ~/.cache/ms-playwright
          key: playwright-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}
          restore-keys: |
            playwright-${{ runner.os }}-

      - name: Install Playwright Chromium
        run: pnpm exec playwright install chromium --with-deps

      - name: Playwright smoke
        env:
          NEXT_PUBLIC_SENTRY_DSN: ${{ secrets.SENTRY_DSN_CI }}
          NEXT_PUBLIC_POSTHOG_KEY: ${{ secrets.POSTHOG_KEY_CI }}
          NEXT_PUBLIC_POSTHOG_HOST: https://us.i.posthog.com
          IDENTIFICATION_PROVIDER_MODE: stub
          DATABASE_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          DATABASE_POOL_URL: postgres://postgres:postgres@localhost:5432/folhario_test
          SUPABASE_SERVICE_ROLE_KEY: test
          NEXT_PUBLIC_SUPABASE_URL: http://localhost:54321
          NEXT_PUBLIC_SUPABASE_ANON_KEY: anon
          SENTRY_RELEASE: ${{ github.sha }}
        run: pnpm test:e2e

      - name: Upload Playwright report
        uses: actions/upload-artifact@v4
        if: ${{ !cancelled() }}
        with:
          name: playwright-report
          path: playwright-report/
          retention-days: 14
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI runner -> Postgres service container | Service-container credentials are ephemeral per job |
| CI runner -> Sentry/PostHog ingest | Secrets live in GitHub repo secrets, never in source |
| Build artifact -> Playwright report | Report uploaded as actions/upload-artifact (private per repo ACL) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | CI secrets leaked in build logs | mitigate | GitHub Actions automatic secret redaction; no `echo` of `NEXT_PUBLIC_SENTRY_DSN` or `NEXT_PUBLIC_POSTHOG_KEY` in any step. Playwright report upload does not include env. |
| T-08-02 | Tampering | Malicious dependency in pnpm-lock.yaml | mitigate | `pnpm install --frozen-lockfile` — any lockfile mutation fails CI. Dependabot + review gate (future) for upgrade PRs. |
| T-08-03 | Denial of Service | Runaway integration tests holding Postgres connections | mitigate | `timeout-minutes: 20` on the job; `testTimeout: 30_000` in vitest integration project config (Plan 01). |
| T-08-04 | Repudiation | Source-map upload leaking auth token | mitigate | Pitfall 7: `SENTRY_AUTH_TOKEN` NEVER set in Phase 1 CI. Upload is Phase 12 `deploy-production.yml` only. |
| T-08-05 | Elevation of Privilege | `pull_request_target` event granting full secret access to fork PRs | mitigate | Workflow uses `on: pull_request` (NOT `pull_request_target`). Fork PRs run without secrets; CI-gated diagnostics assertions tolerate empty DSN/key (see Plan 07 `if (process.env.CI)` gate). |

Threats deferred: Dependabot auto-merge policy (post-Phase-1 ongoing); branch protection rules on `main` (operator task — document in Phase 12); runner image hardening (accept GitHub-hosted default for MVP).
