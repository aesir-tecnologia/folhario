## New Compositions (Phase 5)

### 1. Plant Card (PRD §17 line 911 — locked geometry)

The fundamental atom of the catalog grid. NEVER substituted for a generic card.

| Property | Light value | Dark value |
|----------|-------------|------------|
| Background | Warm Ivory `#FFFDF7` | Embered Surface `#231E1A` |
| Border radius | 16 px | 16 px |
| Photo aspect ratio | 4 : 5 (portrait, fills card width, top of card) | same |
| Inner padding (below photo) | 16 px (all sides) | same |
| Elevation | `box-shadow: 0 2px 12px rgba(20,52,36,0.06)` | 1 px solid Hairline Umber `#3A332B` (no shadow — invisible on near-black) |
| Tap affordance | Whole card — opens `/catalog/[plantId]` | same |
| Press state | Scale 0.985 (springs.primary), reduces to opacity 0.92 under reduced motion | same |
| Card-to-card gap | 16 px (`space-4`) | same |

**Card content stack (top → bottom):**

1. **Photo (4:5)** — `next/image` from signed URL (D-20, 24 h TTL); `alt={`Foto de ${nickname || name}`}` (UI-22 + Phase 3 alt rule).
2. **Name** — Plus Jakarta Sans 16 / 24, weight 600, Forest Ink / Moonpaper. Single line, ellipsis on overflow. Below photo, 12 px top spacing.
3. **Nickname (optional)** — Plus Jakarta Sans 14 / 20, weight 400, Calm Slate / Lantern Slate. Wrapped in `<i>` ONLY if it semantically resembles a Latin name; nicknames are casual ("Meu xodó"), so plain regular. Single line ellipsis. 4 px below name.
4. **Location** — 14 / 20 weight 400, Calm Slate / Lantern Slate, prefixed by 14 px Lucide `MapPin` icon (1.5 stroke), 4 px gap. 8 px below nickname (or below name if no nickname).

**Card skeleton (during load — PRD §17 line 968):**

- 4 : 5 Hairline Beige / Umber photo block.
- 60 % width title line (Hairline Beige / Umber, 16 px tall, 4 px radius).
- 40 % width metadata line (8 px below title, 12 px tall).
- Shimmer left → right 1.4 s in Warm Ivory / Embered at 40 % opacity (Phase 3 `animate-shimmer` utility).
- 300 ms gate before render (Phase 3 D-27); reduced motion → static block + 80 ms fade.

**Banned for plant card:**

- NO photo overlay text (always below photo).
- NO color-tinted photo treatment (raw photo, no filter).
- NO badge / chip overlays in Phase 5 (Phase 7 may add toxicity badge to *care card*, NOT plant card).

### 2. Catalog Grid (UI-07, CAT-10)

Phase 3 D-23 ships per-tab scroll preservation; Phase 5 reuses.

| Viewport | Columns | Outer gutter | Card-to-card gap |
|----------|---------|--------------|------------------|
| ≤ 375 px | 2 | 20 px | 16 px |
| 376 – 599 px | 2 | 20 px | 16 px |
| 600 – 899 px | 3 | 20 px | 16 px |
| ≥ 900 px | 4 | 32 px | 16 px |

**Breakpoint discipline:** 375 / 600 / 900 ladder is locked by PRD §17 line 993 — chosen so the 4 : 5 card lands a whole number of columns at every tier. NEVER substitute a 768 / 1024 ladder.

**Reveal motion:** 60 ms cascade per item, opacity 0 → 1 + translateY 8 px → 0 (PRD §17 line 1026; Phase 3 motion contract). Reduced motion: collapses to instant 120 ms opacity fade for the whole list.

**Loading state:** N skeleton cards (matching expected page size, default 50 — D-12) render inside the grid layout itself (no container shift).

**Pagination affordance:** Cursor-driven (D-12). Sentinel element below last card uses `IntersectionObserver` to trigger next-page fetch. Loading state appends 6 skeleton cards at the bottom. NO "Load more" button (matches PRD §17 anti-button-spam ethos).

**Banned for grid:**

- NO horizontal scroll (Phase 3 layout-slop ban).
- NO masonry / Pinterest layout — strict grid only.
- NO category-section dividers (sort order = single visual order).

### 5. Manual Add Page (UI-07, CAT-02, CAT-03 — D-01)

**Route:** `/catalog/add`. **Layout:** single-screen full-height form (no wizard — PRD §17 anti-wizard ethos). Bottom-nav remains visible.

**Field order (D-01 + Claude's discretion within "name + photo first"):**

1. **Photo picker** (required, ≥ 1) — full-width card-shaped tap target (4 : 5 aspect, Warm Ivory / Embered bg, 16 px radius, 1.5 px Hairline dashed stroke when empty). Tap opens native file/camera picker. After selection, renders local `URL.createObjectURL` preview immediately (D-01 — bytes deferred to submit). Selected state shows photo + small "Trocar foto" tertiary text link beneath.
2. **Name** (required) — `<TextInput>` from Phase 3, label "Nome", 16 / 24 body. `autocomplete="off"`.
3. **Apelido** (optional) — `<TextInput>`, label "Apelido (opcional)".
4. **Localização** (optional) — `<LocationCombobox>` (Phase 5 composed primitive; see below).
5. **Data de aquisição** (optional) — `<TextInput type="date">` per Phase 3 input contract; pt-BR formatting via `Intl.DateTimeFormat('pt-BR')` on display.
6. **Notas** (optional) — `<textarea>` styled like `<TextInput>` (Warm Ivory bg, 1.5 px stroke, focus → Canopy stroke), min height 96 px, max-height 240 px with scroll.

**Submit button** (sticky-bottom inside the page above the bottom nav, with safe-area inset-bottom padding):

| State | Label (i18n key) | Copy | Visual |
|-------|-------------------|------|--------|
| Idle | `catalog.add.submit` | `Adicionar à minha estante` | Canopy primary, full width, 48 px tall |
| Submitting | `catalog.add.submitLoading` | `Adicionando…` | Same fill, label replaced; button disabled. Sonner toast progress not used (button label is the indicator). |
| Read-only mode | (button HIDDEN) | — | Banner active, page falls back to disabled view (D-21) |

**Validation contract (D-04 — tightened to ≥ 2 errors threshold):**

- **Per-field** (always, regardless of count):
  - 1.5 px Overdue Rust / Copper stroke on the input.
  - Filled `AlertCircle` Lucide icon (16 px) inside the input on the right, Overdue Rust / Copper.
  - Helper line below input, Plus Jakarta Sans 14 / 20 weight 400 Overdue Rust / Copper.
  - Field has `aria-invalid="true"` and `aria-describedby` pointing to the helper text id.
- **Summary block** (only when ≥ 2 fields invalid):
  - Renders above the photo picker, 16 px below page title.
  - Plus Jakarta Sans 14 / 20 weight 600 Forest Ink / Moonpaper headline: "Falta preencher: {fields}".
  - 4 px Overdue Rust / Copper left border, Warm Ivory / Embered bg, 8 px radius, 16 px padding.
  - Body: anchor links per error, comma-separated, each focusing the corresponding input on click.
  - `role="alert"` announces full phrase on first render.
- **First invalid field** auto-focuses on submit (regardless of count).
- **Color discipline:** validation uses Overdue Rust `#A14A2C` (light) / Overdue Copper `#C96A44` (dark). NEVER Urgent Poppy / Blossom (those are toxicity + destructive only — Phase 3 color contract).

**Validation messages** (i18n keys under `catalog.add.errors`):

| Key | pt-BR copy |
|-----|------------|
| `nameRequired` | `Dê um nome para sua planta.` |
| `photoRequired` | `Adicione pelo menos uma foto.` |
| `photoTooLarge` | `A foto está muito grande. O app vai comprimi-la antes de enviar.` (informational; client-side compression handles per Phase 2 INFRA-19) |
| `photoGpsRejected` | `Esta foto contém localização. Reenviamos sem essa informação por privacidade.` (informational; client-side strip handles per Phase 2) |
| `acquisitionDateInvalid` | `Use o formato dd/mm/aaaa.` |
| `summaryHeader` | ICU `Falta preencher: {fields}` (anchor links) |

**Submit failure (network / server error — UI-19 Phase 3 inline error contract):**

- Sonner toast bottom-center, persistent until dismissed: `Não conseguimos adicionar agora. Tente novamente em instantes.` (i18n key `catalog.add.submitFailure`)
- Photo bytes retained client-side (the preview persists; user can re-submit without re-picking).
- NO full-screen red wall (banned).

### 12. InlineEditField (D-05 — NEW PRIMITIVE)

**File:** `src/shared/ui/inline-edit-field.tsx`. **Variants:** `text` (single-line) / `textarea` / `date` / `combobox`.

**Props contract:**

```ts
type InlineEditFieldProps = {
  label: string; // i18n-resolved
  value: string | null;
  placeholder: string; // i18n-resolved
  variant: "text" | "textarea" | "date" | "combobox";
  onSave: (newValue: string) => Promise<void>;
  readOnly?: boolean;
  required?: boolean;
  // combobox-only
  options?: ComboboxOption[];
  // textarea-only
  minRows?: number;
  maxRows?: number;
};
```

**State machine:**

```
read → tap → editing → blur/Enter/Cmd+Enter → saving → success → read
                ↓                                      ↓
               Esc                                   error
                ↓                                      ↓
               read                                   read (with toast)
```

**Visual states (per § Plant Profile inline-edit visual states above):**

- `read`, `read-empty`, `read-hover` (desktop), `editing`, `saving`, `error`, `read-only`.

**Saving indicator (UI-22 redundant cue):**

- Inline text label `Salvando…` next to value (not on it). Plus Jakarta Sans 14 weight 400 Calm Slate / Lantern Slate.
- NO circular spinner.
- NO color-only signal (text label IS the redundant cue).

**Optimistic update + rollback (D-06):**

- Save fires PATCH; UI updates to new value immediately.
- On PATCH success: server response merged into TanStack Query cache (D-06 last-write-wins).
- On PATCH failure: UI reverts to pre-edit value; sonner toast `Não conseguimos salvar agora — tentar de novo?` with retry action.

**Required-field guardrail:**

- For required fields (e.g., `name`), Esc on empty value reverts to previous valid value.
- Submit (blur / Enter) with empty value: stays in editing state, applies validation visual (1.5 px Overdue stroke + alert icon + helper line "Não pode ficar vazio." i18n key `catalog.profile.fields.name.requiredError`).

**A11y:**

- Read state: `role="button"` on the value text, `aria-label={label + ": " + (value || placeholder)}`, `tabIndex={0}`.
- Tap or Enter / Space activates editor.
- Editor state: native input element with `aria-label={label}`, `aria-invalid` when in validation error.
- Saving state: `aria-busy="true"` on the field wrapper.
- Error state: `aria-describedby={errorTextId}`, `role="alert"` on the error text container.
