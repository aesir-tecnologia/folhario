## Typography

PRD §17 Typography is authoritative. Phase 5 surfaces use 5 sizes across the editorial + interface families. Three weights span both fonts (Source Serif 4 w500, Plus Jakarta Sans w400/w500/w600). The template heuristic of "exactly 3-4 sizes / exactly 2 weights" does not apply: PRD §17 mandates a 5-size ladder (32 hero, 24 title, 20 plant-name, 16 body/button, 14 section-label/metadata) and 3 weights (the editorial family is single-weight w500 in catalog use; the interface family carries body w400, label w500, button/section w600). Phase 5 cannot reduce either count without breaking the locked design system.

> **Exception declarations (machine-parseable for checker):**
>
> ```yaml
> size_exception_basis: "PRD §17 mandates 5 sizes — 32 hero / 24 title / 20 plant-name / 16 body+button / 14 section-label+metadata; cannot reduce without breaking the locked design system"
> weight_exception_basis: "PRD §17 mandates 3 weights — w500 single editorial weight + w400/w500/w600 interface ladder; cannot reduce without breaking the locked design system"
> ```

|------|------|-------------|--------|------------------|

**Line-height range:** 1.4-1.55 (PRD §17 Typography — "Respect browser zoom + native Dynamic Type / Android font-scale to LARGEST setting. Line-height 1.4-1.55. Fixed-height containers grow to fit scaled text — clipping = bug").

**Hard prohibitions Phase 5 must honor (PRD §17 Banned patterns):**
- NEVER substitute Inter, Geist, Satoshi, generic serifs (Times, Georgia, Garamond, Palatino), or system fonts
- NEVER mix Source Serif 4 into buttons or form fields
- NO all-caps headlines (uppercase reserved for 14px section labels @ +4% tracking)
- NO condensed/ultra-tight tracking
- NO fixed-height text containers that clip when text scales

## Motion (Phase 5 surfaces)

PRD §17 Motion is authoritative. Phase 5 motion uses spring physics, not easing curves.

| Element | Spec |
|---------|------|
| Catalog grid item reveal | 60ms cascade per item — opacity 0→1 + translateY 8px→0 (PRD §17 Motion — "Staggered orchestration: catalog grid + care-card rows reveal with 60ms cascade per item ... NEVER mount lists instantly") |
| Modal sheet enter | Spring `stiffness: 120, damping: 18, mass: 1`, ~240ms (PRD §17 Motion — primary interactions) |
| Modal sheet exit | Spring same params, ~180ms |
| Inline-edit field focus → input transition | Spring same params; pencil icon fades out 120ms in parallel |
| Capture button breathing loop (Home empty) | Scale 1.00 → 1.02 over 3.2s, infinite, ease-in-out (THE ONLY perpetual micro-interaction) |
| Loading skeleton shimmer | Left-to-right 1.4s in Warm Ivory/Embered at 40% opacity, render only after 300ms delay |

**`prefers-reduced-motion: reduce` fallbacks (PRD §17 Motion + Accessibility — non-negotiable):**
- Breathing loop stops at rest
- Shimmer disabled, becomes static block
- 60ms cascade collapses to instant 120ms opacity fade
- Spring transitions become 120ms linear crossfade
- Motion is NEVER sole indicator of state change

**Hard prohibitions (PRD §17 Banned patterns):**
- Animate ONLY via `transform` + `opacity`. NEVER `top, left, width, height`
- NO backdrop-filter animations
- NO confetti, neon, glow, drop-shadow fakery
- NO bouncing chevrons, "role para baixo", scroll-hint arrows
- NO custom mouse cursors
- NO hover-dependent interactions (hover is decorative amplification only, NEVER load-bearing)

## Accessibility Contract (Phase 5)

PRD §18 is authoritative. Phase 5 surfaces must satisfy:

### Image alt text (PRD §18 — non-negotiable)

| Surface | Alt text formula |
|---------|------------------|
| Catalog card cover | `name` (or `name (nickname)` when nickname is set). Example: `"Samambaia"` or `"Samambaia (Maria)"` |
| Plant Profile cover | `name (nickname)` when nickname is set; otherwise `name` |
| Photo Journal entry | `Foto de <name>, <pt-BR locale date>`. Example: `"Foto de Maria, 12 de abril de 2026"` (uses `date-fns-tz` with `User.timezone`) |
| Sage line-art empty-state illustration | `aria-hidden="true"` (decorative — marked `accessibility hidden`) |
| Inline pencil edit affordance | `aria-label="Editar [field name]"` (icon-only button needs accessible name) |

NO empty alt allowed. NO filename-based alt. NO AI auto-captioning in MVP.

### Screen reader announcements

- Live regions for async state: catalog list load completion, plant create completion, plant delete completion, photo journal entry add completion (PRD §18 — "Live regions for async state")
- Sort change announcement: "Ordenado por [option]" via `aria-live="polite"`
- Loading: "Carregando suas plantas" announced when skeleton renders past 300ms threshold

### Focus management

- Global focus ring: 3px Canopy/Sprout @ 40% opacity, offset 2px outside element bounding box, 8px corner radius matching element shape (PRD §17 Layout)
- Tab order = visual reading order (PRD §17 + §18)
- Modal sheets trap focus until dismissed (PRD §17 Modal sheet)
- After route change (e.g. tap catalog card → Plant Profile), focus moves programmatically to main content region (PRD §17 Layout)
- 40% opacity is MIN that clears 3:1 UI-graphic floor on Paper/Night Cream — DO NOT lower to 20%

### Keyboard interaction

- Catalog grid: arrow keys move focus between cards (PRD §18 implicit; native HTML semantics + custom keyboard handler), Enter/Space activates
- Location combobox: arrow keys move highlight, Enter selects, Escape closes, Tab moves out of combobox
- Lightbox: arrow keys cycle PhotoEntries, Escape dismisses, Tab moves through bottom strip actions
- Modal sheets: Escape dismisses (in addition to visible "Fechar"), Tab cycles within trap

### Color is never sole signal (PRD §18)

- Validation errors: 3 redundant signals (1.5px Overdue stroke + filled alert icon + Overdue helper line) per PRD §17 Inputs
- Read-only banner: icon + text (PRD §18)
- Offline banner: icon + text (PRD §18)
- Sort selection state: visual highlight + checkmark icon + `aria-checked="true"`

### Haptics (Phase 5 surfaces only — PRD §18)

- "Excluir" destructive confirm tap → medium impact (PRD §18 — "Destructive confirm tap → medium impact")
- First-ever plant added → success notification, ONCE (PRD §18 — "First plant added / care streak milestone → success notification, ONCE")
- Transient errors (network, validation) → NO haptic (PRD §18 — "haptic noise on non-critical = trains users to ignore")

### Localization (PRD §17 + INFRA-23)

- `<html lang="pt-BR">` (Phase 1 already shipped via next-intl)
- All strings via i18n layer — NO hardcoded copy
- Numbers/dates/currency via `Intl.*` with `pt-BR` (e.g. `"12 de abril de 2026"`, `"R$ 29,90"`)
- Body copy MAY use `hyphens: auto` for long scientific names; headlines do NOT hyphenate
- Latin scientific names wrapped in `<i lang="la">` (PRD §17 Localization)

### Safe areas + responsive

- Full-height surfaces use `min-h-[100dvh]` (PRD §17 — NEVER `h-screen`)
- Top padding honors `env(safe-area-inset-top)`, bottom honors `env(safe-area-inset-bottom)` (PRD §17 Safe areas)
- Bottom nav reserves `env(safe-area-inset-bottom)` inside its padding (consumed from Phase 3)
- Body text minimum 16px regardless of viewport (PRD §17 Safe areas)
- Catalog grid breakpoints: 2 cols ≤375px, 3 cols 600-899px, 4 cols ≥900px (NEVER 768/1024)
- Horizontal scroll forbidden on Phase 5 mobile surfaces (the only allowed horizontal-scroll exception is Home "Today's tasks" strip, which lands in Phase 8)
