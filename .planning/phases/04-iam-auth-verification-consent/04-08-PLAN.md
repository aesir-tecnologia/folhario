<objective>
Implement the password reset flow per CONTEXT D-09, D-10, D-11. The request endpoint always returns 200 (no enumeration); the actual user lookup + token mint + email dispatch happens **inline within the route handler** (no intermediate Inngest function — Plan 04 Decision Conflict on D-11 vs D-16's "exactly 8 functions" directive). The consume endpoint validates the SHA-256 token in a transaction and updates the password via `authAdapter.adminUpdatePassword` (Codex HIGH #3) — without invalidating existing JWTs (per AUTH-12).

Purpose: AUTH-11 (always-200 anti-enumeration) and AUTH-12 (token consume + admin.updateUserById; existing JWTs valid). Resolved by D-11's enqueue-first pattern: the public endpoint is fast and unconditional; user existence is checked async (the route's lookup runs while the response is being built; the email dispatch happens via inngest.send AFTER response).

**Codex HIGH #2 fix:** consumePasswordReset wraps consumeResetToken + authAdapter.adminUpdatePassword in `db.transaction(...)`. If the password update fails, the token consume is rolled back (preventing the user from being locked out with a consumed token they can't reuse).

**Codex HIGH #3 fix:** consumePasswordReset uses `authAdapter.adminUpdatePassword`, never `supabase.auth.admin.updateUserById` directly.

**Codex HIGH #6 fix:** Playwright E2E covers cookie-bearing reset → login flow.

**Codex HIGH #8 fix:** Per the orchestrator's spec, Inngest event id was `password-reset-request/{email}` (24h dedup) — too broad, blocks legitimate retries after 1h token expiry. Since this plan eliminates the intermediate `iam/password-reset-requested` function entirely (Plan 04 Decision Conflict resolution), the Inngest event id is now `password-reset/{tokenId}` for the `notifications/email.requested` event. The token id is unique per mint, so dedup is per-token (not per-email). Rapid retry-from-same-IP defense lives in the route's per-IP throttle (`withThrottle("password-reset-request", "always", ...)`).

**D-31 fix:** Both routes are JSON-only — `request.json()`, never `request.formData()`.

Output: 1 new repository (reset-tokens), 2 application use-cases, 2 route handlers, 1 vitest integration test (use-case + token + AUTH-12 JWT-stability), 1 Playwright E2E (cookie + login-after-reset).

    // Phase 4 D-09 + AUTH-11. Token hash storage; raw exists only in URL.
    import { eq, and, isNull, sql } from "drizzle-orm";
    import { db } from "@contexts/iam/infrastructure/db/client";
    import { passwordResetTokens } from "@contexts/iam/infrastructure/db/schema";
    import { mintToken } from "@shared/crypto/tokens";
    import { createHash } from "node:crypto";
    import type { DbOrTx } from "@contexts/iam/infrastructure/db/types";

    export async function revokeUnusedResetTokens(userId: string, dbOrTx: DbOrTx = db): Promise<void> {
      await dbOrTx.update(passwordResetTokens)
        .set({ consumed_at: new Date() })
        .where(and(eq(passwordResetTokens.user_id, userId), isNull(passwordResetTokens.consumed_at)));
    }

    export async function mintResetToken(opts: {
      userId: string;
      sentToEmail: string;
    }, dbOrTx: DbOrTx = db): Promise<{ tokenId: string; rawToken: string }> {
      await revokeUnusedResetTokens(opts.userId, dbOrTx);
      const { raw, hash } = mintToken();
      const expiresAt = new Date(Date.now() + 60 * 60 * 1000);  // D-09: 1h per AUTH-11
      const [row] = await dbOrTx.insert(passwordResetTokens).values({
        user_id: opts.userId,
        token_hash: hash,
        expires_at: expiresAt,
        sent_to_email: opts.sentToEmail,
      }).returning({ id: passwordResetTokens.id });
      return { tokenId: row!.id, rawToken: raw };
    }

    export async function consumeResetToken(rawToken: string, dbOrTx: DbOrTx = db): Promise<{ userId: string } | null> {
      const hash = createHash("sha256").update(rawToken).digest("hex");
      const result = await dbOrTx.execute<{ user_id: string }>(
        sql`WITH t AS (
              SELECT id, user_id FROM public.password_reset_tokens
              WHERE token_hash = ${hash} AND consumed_at IS NULL AND expires_at > now()
              FOR UPDATE
            )
            UPDATE public.password_reset_tokens prt SET consumed_at = now()
            FROM t
            WHERE prt.id = t.id
            RETURNING prt.user_id`
      );
      const row = result[0];
      return row ? { userId: row.user_id } : null;
    }
